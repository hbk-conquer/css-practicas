Esto es un ejemplo de cómo se utiliza un bloque de estilos desde ésta página

El texto arriba escrito es un h2 y aquí estoy escribiendo dentro de un p

En este caso la estructura del bloque de estilos, solamente contiene un estilo de color para <h2> y <p> en este mismo archivo html.

Como no está estructurado con una envoltura de <main> el texto del copyright que se encuentra en el <footer> y dentro de un <p>, también se ve afectado por el cambio de color de los estilos previamente asignados dentro de la etiqueta <style> de este mismo archivo html.
